# weekly-indie-game-radar

每周独立游戏 / 休闲游戏榜单调研与可视化交付 Skill（周榜雷达）。面向 1-3 人小团队的独立开发者：每周从 Google Play、Apple App Store、Steam 三平台抓取榜单新品与排名上升游戏，按硬门槛筛选出值得借鉴的优质游戏，做 12 维打分与深度分析，最终交付交互看板（汇总卡片页 + 左列表右详情 + 图表 + 游戏真实截图，适配手机竖屏）与飞书分享文档。

## 适用场景

- 每周定期调研三平台榜单（本周新上榜 / 排名显著上升的游戏）
- 从爆款中提炼可复用的玩法机制、变现设计与美术方向
- 生成可供团队同事讨论的交互看板与飞书文档
- 关注小团队可复刻、低技术门槛、蓝海赛道的产品机会

## 工作流（五阶段）

```
阶段1 榜单采集（三平台并行）→ 阶段2 硬门槛筛选 → 阶段3 深度分析
→ 阶段4 打分与脚本核验 → 阶段5 交互看板 + 飞书文档交付
```

1. **榜单采集**：Google Play 美区免费/畅销/新品榜、App Store 美区与中区免费/付费/畅销/新品榜、Steam 新品热销/好评上升榜；7 日热度用 querygame Movers 判定；关键数字经官方 API 抽查核验。
2. **硬门槛筛选**：时间窗口、排名门槛、品类排除（3A/MMO/卡牌SLG/棋牌博彩/超休闲缝合）、团队体量（≤50 人或成本 ≤50 万美元）、口碑门槛（移动 ≥4.0 且评论 ≥1000；Steam 评论 ≥200 且好评率 ≥80%）、跨平台去重、地区偏好。
3. **深度分析**：每款输出一句话定位、玩法亮点（单局循环 + 元循环）、核心卖点、资源循环、变现设计、口碑洞察（好评/差评关键词，实际抓取）、独立开发者借鉴建议、注意事项。
4. **打分与核验**：12 维打分（玩法创新 / 核心循环 / 美术可复刻 / 技术门槛 / 内容量 / IAA 潜力 / IAP 友好 / 上手门槛 / 题材热度 / 竞争烈度 / 可借鉴度 / 合规风险），按加权公式计算综合分，并用脚本重算核验：

   ```bash
   python scripts/validate_scores.py games.json
   ```

   综合分 = 玩法创新×0.20 + 美术可复刻×0.15 + 技术门槛×0.10 + (IAA潜力+IAP友好)/2×0.15 + 可借鉴度×0.20 + 其余 6 维均值×0.20

5. **交付**：交互看板（复用上周 HTML 为模板，更新数据与素材）→ html 自检 → 发布线上链接；飞书分享文档（看板入口 + Top5 速览 + 讨论问题 + 数据口径声明）。

## 使用方式

在支持 Skill 的 Agent 环境中，直接说「开始本周榜单调研」即可触发；Skill 会自动复用上周看板作模板并跟进观察项。

评分脚本用法：

```bash
python scripts/validate_scores.py games.json [--tolerance 0.02]
# games.json: [{"id":"rr","dims":[7,8,8,8,6,9,7,9,8,6,9,10],"score":7.97,"iaa":9}, ...]
```

## 数据纪律

- 每个数字必须有信源或可复现计算；下载量/收入为估算时写清口径（GP 按 AppBrain 安装量与榜单位置推算；Steam 按评论数 ×30-60 系数，未扣平台分成）。
- 无上周榜单快照时，环比上升一律标「待核实」，禁止编造。
- 12 维打分与深度分析为主观判断，报告内明示「分析师主观打分」口径。
